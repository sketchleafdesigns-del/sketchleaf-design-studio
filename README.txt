# Sketchleaf Design Studio — Commercial Landing Page

This package contains the edited landing page and the supplied commercial videos.

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local web server so video assets load reliably.

Example:
- Python: `python -m http.server 8000`
- Then open `http://localhost:8000/`
